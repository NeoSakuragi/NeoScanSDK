Steps

Palettes

Body palette 0 of each set, as stored in the program ROM: 16 colours per set, $1D9000 + id × $400 for the regular set and +$200 for the mirror set, which the second player wears when both sides pick the same fighter. Colour 0 is transparent; in ROM it holds the palette's number, which the game overwrites.

Measured physics

Pixels per frame. Walk, jump launch and gravity come from each character's record at $7AF16 + id × 128 in the program ROM; walking back is ¾ of the walk speed and the jump drift equals it, as measured in MAME. Knockdown values were measured on Terry; their gravity is shared by every reaction.
