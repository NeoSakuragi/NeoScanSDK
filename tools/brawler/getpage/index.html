Neo Geo beat 'em up, Android beta.

brawler-@NAME@.apk · @SIZE@ MB · Android 8 or newer

Install

  1. Tap Download the app, then open the downloaded file.
  2. If Android asks, allow your browser to install apps, then tap Install.
  3. Open Brawler and sign in with the tester account Bruno gave you.
  4. The game downloads itself on the first start (about 50 MB, Wi-Fi recommended).

Updates

New versions of the game arrive by themselves. When a new version of the app exists, the app offers it on its start screen and installs it for you.

Found a bug or have an idea? Hold the Feedback button in the game and talk: your note goes straight to the developer with a replay of what just happened.
